# 文章标题与目录

插件会读取正文中的 `h1`～`h6` 标题，生成文章目录。Markdown 中的 `#`～`######` 会生成相应标题，加粗文本不会生成目录。

## 标题层级

建议按顺序使用标题，避免跳级。例如：

```markdown
## 安装
### 后台设置
### 插件配置
## 使用
```

目录以文章中实际出现的标题级别排序并缩进。如果整篇文章只有 `h2` 和 `h4`，目录会显示为两层，不为缺失的 `h3` 保留一层。

## 位置和显示

目录默认在右侧。屏幕宽度达到隐藏阈值，或正文两侧空间不足时，会自动隐藏；可以通过右下角的目录按钮尝试显示。

位置、隐藏宽度、横向滚动条和编号的设置见[文章目录配置](/reference/config/article#articledirectory-文章目录)。
