# 常见问题

## 保存配置后没有变化

1. 确认已开通 JS 权限，博客皮肤为 `SimpleMemory`，并勾选「禁用模板默认 CSS」。
2. 核对 CSS 与脚本版本；页面只引入一次插件。
3. `window.cnblogsConfig` 放在插件脚本之前。添加配置时合并字段，不要在后面重新赋值覆盖原配置。
4. 打开浏览器控制台，检查语法错误；在 Network 面板检查脚本和资源请求。

安装位置和完整示例见[安装配置](./install)。

## 页面一直 Loading，或者部分内容没有样式

先检查插件入口、脚本分包和 CSS 是否加载成功。自托管时必须上传整个 `dist/` 目录，不能只上传入口脚本。也要检查配置中的图片和外部脚本是否可以通过 HTTPS 访问。

可以临时[隐藏 Loading 遮罩](/reference/loading#隐藏遮罩)查看页面，但隐藏遮罩不会修复加载错误。

## 侧边栏没有分类、标签或排行

先在博客园后台开启对应控件，再确认栏目确实有数据。设置可能有缓存，稍等后刷新。更多排查见[侧边栏数据](./menuData)。

## 文章目录没有显示

正文需要有真正的 `h1`～`h6` 标题；只加粗文字不会生成目录。窄屏或两侧空间不足时目录会自动隐藏，可以尝试右下角目录按钮。相关配置见[文章配置](/reference/config/article#articledirectory-文章目录)。

## 代码出现双行号或高亮不对

不要同时开启博客园与插件的行号。先按[安装教程](./install#代码高亮)核对后台设置，再检查[代码配置](/reference/config/code)。

## 修改日夜模式配置后没有变化

手动切换的模式会保存在 Cookie 中，优先于自动时段选择。可以点击切换按钮或清除站点的 `cnblogs_config_isNight` Cookie 后重试。`nightMode: true` 会覆盖初始化时的模式选择；`enable: false` 则关闭整个切换功能。

## 书单或友链不显示

确认文章正文包含对应的隐藏标记，并将数据写在全局配置中。友链需要按分类提供 `links` 数组，不能直接将好友对象放入 `links.page`。参见[书单页](/reference/bookList)和[友链页](/reference/links)。

## 仍然无法解决

请在 [Issues](https://github.com/BNDong/Cnblogs-Theme-SimpleMemory/issues) 附上博客链接、插件版本、浏览器、复现步骤，以及控制台报错或截图。贴配置前去掉不需要公开的信息。
