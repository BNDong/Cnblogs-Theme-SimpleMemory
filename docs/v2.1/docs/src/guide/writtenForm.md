# 书写规范

富文本编辑器可以使用 TinyMCE，也可以使用博客园的 Markdown 编辑器。

## 标题和代码

| 内容 | TinyMCE | Markdown |
| --- | --- | --- |
| 一级标题 | `<h1>` | `# 标题` |
| 二级标题 | `<h2>` | `## 标题` |
| 引用 | 引用格式 | `> 引用内容` |
| 行内代码 | 行内代码格式 | 用一对反引号包住代码 |
| 代码块 | 插入代码 | 使用代码围栏，并标注语言 |

标题请使用编辑器的标题格式，不要只修改字号或加粗。目录规则见[文章标题与目录](./articleDirectory)。

## 代码折叠

```html
<details>
  <summary>展开代码</summary>
  <pre><code>在这里填写代码</code></pre>
</details>
```

使用富文本编辑器时，将 HTML 添加到源码模式中。

## 提示引用

在段落开头使用 `!>` 或 `?>`，分别显示警告和信息样式：

```markdown
!> 这里是警告内容。

?> 这里是提示内容。
```
