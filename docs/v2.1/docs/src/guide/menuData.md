# 侧边栏数据

如果遇到菜单数据不显示，请以下面的方式进行排查处理。

## v2 支持的栏目

侧边栏会读取博客园返回的最新随笔、标签、随笔分类、文章分类、档案、阅读排行、推荐排行、最新评论和积分排名等数据。控件开启且已有数据，才可能在插件菜单中显示。

`sidebar.submenu` 控制的是栏目是否默认展开，不负责启用后台控件；见[侧边栏配置](/reference/config/basic#sidebar-侧边栏)。

## 栏目不显示

### 开启对应显示设置

在博客园后台「选项 → 控件显示设置」中开启对应栏目并保存。

::: tip 提示
由于博客园有缓存机制，设置后稍等几分钟才会生效。
:::

### 确认栏目已有数据

如果没有相应的数据，即使设置了显示，博客园也不会返回对应的栏目的数据，这样也会造成不显示的问题。

* 随笔分类：『博客设置』--->『随笔』--->『分类』
* 推荐排行：没有获得推荐的文章时，栏目可能不会返回数据。

### 检查博客园返回的数据

如果以上两种方式都不能解决问题，使用此方法进行尝试。

使用浏览器的『开发者工具』搜索HTML代码：

```html
<h3 class="catListTitle">
```

注释掉 class `catListTitle` 的 CSS 设置 `display: none!important`

在开发者工具中检查原始栏目是否包含目标数据；临时修改只用于排查，刷新页面即可恢复。

* 如果这里没有，那可能是官方问题，检查下自己的设置。
* 如果这里有但插件菜单没有，请在 [Issues](https://github.com/BNDong/Cnblogs-Theme-SimpleMemory/issues) 提供博客链接、插件版本和相关截图。
